# Doppler/Edward Medium blog package

Drop these files into the root of `doppleredward-site`:

```text
blog.html
blog/
css/blog-import.css
content/blog/
BLOG_MIGRATION_REPORT.md
blog_manifest.csv
blog_manifest.json
```

The live static site uses the generated HTML files. The Markdown files are included as editable source/archive copies.

Recommended next step: review `blog.html` locally, then publish the HTML/CSS set to a feature branch.
